# Chharizard Assets

Place `banner.png` (recommended 1200×300, transparent PNG) in this folder — the top of the main `README.md` renders it.

Suggested colors matching the Chharizard palette:
- Cyan: `#0abde3`
- Magenta: `#ff2e97`
- Yellow: `#ffd732`

Placeholder image services (until you have a real banner):
- [Banner generator](https://github.com/kyechan99/capsule-render) — auto-generates a gradient banner from a URL
- Example URL: `https://capsule-render.vercel.app/api?type=waving&color=gradient&customColorList=6,11,20&height=200&section=header&text=Chharizard&fontSize=90&fontColor=ffffff&animation=fadeIn`

Drop the banner PNG here as `banner.png` and the README will pick it up.
